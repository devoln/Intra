# Эксперименты с физико-параметрической моделью пианино

Дата: 2026-09-26

## Зачем этот файл

Здесь перечислены альтернативные способы заменить измеренные piano tables более компактной физико-параметрической моделью. В runtime входят только решения, прошедшие слуховую проверку. Остальные направления сохранены как отклонённые эксперименты, чтобы не повторять уже проверенные идеи.

## Генерация амплитуд partials из небольшого числа параметров

Проверялись smooth spectral envelopes, register trends, harmonic cutoff, strike-position comb и локальные voicing-параметры по sample zones. Они не сохраняли достаточно точно локальный spectral fingerprint референса.

**Отклонено:** измеренные/упакованные partial amplitudes дают заметно более точный тембр при приемлемом размере.

## Генерация decay/envelope вместо хранения коэффициентов

Проверялись общие и сглаженные decay laws и компактные параметрические зависимости amplitude/decay. Joint temporal fit `Amp + Decay1..4` хорошо описывает временную форму, но несколько глобальных физических параметров не заменяют локальные особенности по зонам.

**Отклонено как генеративная замена:** joint temporal fit используется для получения компактных измеренных коэффициентов, а не для вычисления всей envelope из нескольких параметров.

## Явная модель нескольких струн и биений

Проверялись unison/beat rate, depth и phase параметры, включая более подробную complex-unison модель.

**Отклонено:** подробная модель заметно дороже, а упрощённые варианты не дают достаточного выигрыша относительно принятого представления.

## Отдельный hammer/contact residual

Проверялись короткий contact transient, residual texture/noise и modal ringdown поверх струны.

**Отклонено:** отдельный слышимый слой делает атаку заметнее референса или дублирует структуру, уже содержащуюся в измеренной модели. Принята короткая contact window с hard reveal уже развившейся струны.

## Полностью процедурная модель вместо tables

Такой вариант имеет смысл только если одновременно сохраняет локальные sample-zone особенности, stereo image и temporal decay, заметно сокращая данные или runtime cost.

**Отклонено на текущем качестве:** найденные параметрические варианты пока уступают packed measured coefficients по точности.
