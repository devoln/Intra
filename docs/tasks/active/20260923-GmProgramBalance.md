# Нормировка GM-инструментов по SF2

Дата: 2026-09-23

## Цель

Привести относительные уровни реализованных GM-инструментов к Titanic 200 GM-GS v1.2 без изменения их тембра.

## Метод

Для одинаковых MIDI note/velocity измеряются dry RMS синтезатора и SF2-референса. Для каждой программы используется относительный gain к Acoustic Grand Piano, поэтому master gain FluidSynth и master gain синтезатора сокращаются из сравнения.

Коэффициент уровня применяется внешним mix-layer после создания внутреннего sampler. Благодаря этому нормировка не меняет random seed, спектр, envelope или другие параметры тембра. Общие внутренние инструменты, используемые несколькими GM-программами, получают один согласованный коэффициент.

## Результат

- Относительные уровни реализованных melodic GM-программ откалиброваны по SF2-референсу.
- Shared physical drum models канала 10 откалиброваны тем же принципом по соответствующим SF2-нотам.
- Program-level нормировка остаётся отдельным уровнем от тембральной модели. Различия формы по регистру или velocity должны исправляться в самой модели, а не дополнительными gain-костылями.

## Инвариант

SF2-нормировка изменяет только относительный уровень инструментов.
