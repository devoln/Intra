# Эксперименты с физико-параметрической моделью пианино

Дата: 2026-09-26 (обновлено 2026-09-27)

## Зачем этот файл

Здесь перечислены альтернативные способы заменить измеренные piano tables более компактной физико-параметрической моделью. В runtime входят только решения, прошедшие слуховую проверку. Остальные направления сохранены как отклонённые эксперименты, чтобы не повторять уже проверенные идеи.

## Генерация амплитуд partials из небольшого числа параметров

Проверялись smooth spectral envelopes, register trends, harmonic cutoff, strike-position comb и локальные voicing-параметры по sample zones. Они не сохраняли достаточно точно локальный spectral fingerprint референса.

**Отклонено:** измеренные/упакованные partial amplitudes дают заметно более точный тембр при приемлемом размере.

## Генерация decay/envelope вместо хранения коэффициентов

Проверялись общие и сглаженные decay laws и компактные параметрические зависимости amplitude/decay. Joint temporal fit `Amp + Decay1..4` хорошо описывает временную форму, но несколько глобальных физических параметров не заменяют локальные особенности по зонам.

**Отклонено как генеративная замена:** joint temporal fit используется для получения компактных измеренных коэффициентов, а не для вычисления всей envelope из нескольких параметров.

## Явная модель нескольких струн и биений

Проверялись unison/beat rate, depth и phase параметры, включая более подробную complex-unison модель.

**Отклонено:** подробная модель заметно дороже, а упрощённые варианты не дают достаточного выигрыша относительно принятого представления.

## Отдельный hammer/contact residual

Проверялись короткий contact transient, residual texture/noise и modal ringdown поверх струны.

**Отклонено:** отдельный слышимый слой делает атаку заметнее референса или дублирует структуру, уже содержащуюся в измеренной модели. Принята короткая contact window с hard reveal уже развившейся струны.

## Полностью процедурная модель вместо tables

Такой вариант имеет смысл только если одновременно сохраняет локальные sample-zone особенности, stereo image и temporal decay, заметно сокращая данные или runtime cost.

**Отклонено на текущем качестве:** найденные параметрические варианты пока уступают packed measured coefficients по точности.

### Направления, прошедшие проверку и достойные продолжения

- **Afterlength / rear-duplex side-branch** — первый устойчивый физический сигнал:
  один демпфированный боковой сегмент с 4 параметрами, отношение длины бокового
  сегмента **0.13 → 0.28** от баса к дисканту; поправки h2 у 75/78/81 сидят на
  первом afterlength-резонансе (`a·n ≈ 0.47/0.50/0.53`); обобщается на holdout,
  где 75+78+81 все убраны из обучения. Оговорка: подобранное отношение не похоже
  на реальные rear-duplex пропорции рояля.
- **`Amp ∝ sqrt(mean DecayRate)`** — теоретический член связи струны с декой без
  нового коэффициента; убирает систематическую НЧ-ошибку (CV 3.54/10.13/6.92 → 2.x).
- **Decay как независимый датчик bridge mobility.** Разности стадий Decay
  предсказывают Amp без участия Amp: low4 RMS 7.91 → 7.10; 2 локальные моды при
  общем `Q≈4`: low4 5.70 → 4.80, p90 9.49 → 6.85, h5–h12 нейтральны.
- **Широкополосный отклик корпуса между гармониками** (по раннему фронту) —
  объясняет верхнюю звонкость h5+ (корреляция с h1–h4 всего ~0.14), переживает
  проверку на утечку; компактные 1–3 моды на зону его почти не сохраняют.
- **Микрозадержка удара между струнами унисона** (2-струнная временная модель):
  holdout 75+78+81 low4 5.71 → 3.54 дБ, но по фазе реальных биений в сыром SF2
  как общий механизм не подтверждается; 3 струны хуже 2.
- **Dense-modal дека** (driving-point mobility): MIDI ≥ 60 held-out p90 12.64 → 9.37;
  root75 h2 предсказывается в roughness-only тесте; как генератор пока не готов
  (нестабильный CV), но как диагностический инструмент ценен.
- **Per-zone hardness по раннему транзиенту**: h1–h4 4.78 → 3.00, но h5–h12 хуже.

### Подтверждённые отрицательные результаты (не повторять)

Отражения/comb-задержка; inharmonicity как координата; модальная масса; контактная
кривизна; rib/inter-rib локализация (переход ~1 кГц есть, геометрии нет); ширина и
длина rib-bay; Stulov hysteresis; hammer `K`+hysteresis; локальный tilt;
3-струнная микрозадержка; глобальные bridge-modes из Decay; дисперсия жёсткой
струны сама по себе; body-cleaning waveguide; стерео-структура сэмпл-сета.

### Методика (это надо помнить при любом следующем фите)

- Packed `Amp` — **латентный intercept** robust decay-fit, а не снимок сырого FFT
  в `DecayOnset`; у разных зон он определён в разное время.
- Штатный joint-fitter берёт **4096-сэмпловый Hann FFT (~93 мс)** с фиксированным
  окном.
- `PianoAttackCoeffs` откалиброваны только до **root81**; 84–93 почти без них.
- Titanic в этом регистре переиспользует тот же Clavinova sample; per-zone
  filter/EQ там нет.
